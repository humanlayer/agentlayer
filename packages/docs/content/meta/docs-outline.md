# AgentLayer Docs Outline

This repo should keep the docs simple: explain how to build an agent, explain which package to reach for, and only then add detailed reference material.

## Writing Principles

- Start with runnable examples before architecture.
- Keep one idea per page.
- Prefer task-based pages over exhaustive concept dumps.
- Write for someone assembling an agent from these packages, not for someone reading the repo for the first time.
- Put package-specific details on package pages instead of repeating them across the site.
- Add `description` frontmatter to every real doc page so `llms.txt` is more useful.
